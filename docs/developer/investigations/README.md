# Investigations

Each file here states a problem the Checker Framework has, the evidence that it
is real, and the questions that have to be answered before committing to a
solution. They are not designs and not plans: they exist so that the first work
on a problem is measurement rather than construction.

A file graduates when its questions are answered. The answers belong in the
file, next to the questions, whether or not they lead anywhere -- a question
answered "no" is as useful as one answered "yes", and cheaper to record than to
re-derive.

Written September 2026.
